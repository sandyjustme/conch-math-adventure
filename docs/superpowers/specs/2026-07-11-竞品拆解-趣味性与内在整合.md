# 竞品拆解报告：趣味性与"内在整合"

> 日期：2026-07-11
> 目的：在改代码前，先拆解标杆产品的**关键交互**，对齐"海螺喵"的设计语言。
> 结论先行：海螺喵当前"游戏和学习是两张皮"，需要从**巧克力西兰花**结构转向**内在整合**结构。

---

## 0. 一句话诊断

学术界把教育游戏最常见的失败叫 **"裹了巧克力的西兰花"**（chocolate-covered broccoli，Amy Bruckman 1999）：用好玩当奖励，哄孩子吞下枯燥的学习。

海螺喵当前正是这个结构：

| 现状模块                                   | 本质                                                      |
| ------------------------------------------ | --------------------------------------------------------- |
| AI 对话讲题 + 打字回答                     | 学习（西兰花，且是厌学孩子最抗拒的"读长文字 + 打字"形式） |
| 拖数轴、贝壳、咖啡兑换、2 个 Canvas 小游戏 | 奖励/装饰（巧克力，且与数学**无关**）                     |

**问题**：数轴拖动不影响任何东西；游戏角是独立的；贝壳换咖啡与"负数怎么比大小"没有一根线相连。孩子学的时候不好玩，好玩的时候不学，两者互相稀释——这正是"趣味性和学习性都低于预期"的根因。

**目标结构**：**内在整合（intrinsic integration）**——数学内容本身就是游戏机制，而不是包在外面的壳。ST Math 产品总监原话："我们做的正好相反——先找到教学目标，再找一种游戏化地跟它互动的方式。"

---

## 1. DragonBox（标杆中的标杆：把代数变成纯拼图）

**核心隐喻**：解方程 = 把小盒子（未知数 x）旁边的牌全部清空，让盒子独处。

**关键手势 → 数学规则**（全程零文字，靠手感发现规则）：

| 手势                       | 屏幕反馈                                     | 对应数学规则           |
| -------------------------- | -------------------------------------------- | ---------------------- |
| 点"漩涡卡"                 | 卡片消失                                     | 这是 0，可以去掉       |
| 点牌堆里的卡               | 白天卡翻成黑夜卡                             | 取相反数（正↔负）      |
| 把黑夜卡滑到对应白天卡上   | 两卡合并成漩涡（=0）                         | a + (−a) = 0 相消      |
| 从牌堆拖一张卡到一侧       | 屏幕**冻结**，另一侧出现凹槽提示必须也放一张 | 等式两边要做同样的操作 |
| 乘法：拖动时自动出现分隔线 | 引导把配对卡放到分数线下                     | 约分 / 乘除            |

**值得抄的三条**：

1. **不可能走错**——非法操作，游戏物理上不让你做（拖一边就冻结，逼你补另一边）。孩子不会因为"又错了"而崩溃。
2. **零文字 onboarding**——Level 1 只放漩涡卡，孩子自然会去点，自己发现"点=消除"。规则是**玩出来的，不是讲出来的**。
3. **只奖励"化到最简"**——星星只给最少步数/最简结果，把"化简"这个数学习惯变成通关动机。

**不能抄的**：几乎无教学讲解，靠家长补"这其实是代数"；练习量不足以形成熟练度。

## 2. ST Math（"无字数学"，内在整合的教科书）

**核心隐喻**：帮企鹅 JiJi 走到屏幕对面。数千道题目**目标永远一致**，孩子只需专注"怎么做到"。

**关键循环 = 感知-行动循环（perception-action cycle）**：

```
预测（我觉得这样能行）→ 行动（点/拖）→ 感知（动画演出后果）→ 对比（对不对）→ 修正
```

**反馈设计是全产品最狠的地方**——反馈不是"对/错 + 提示"，而是**信息化反馈（informative feedback）**：

- 答对：JiJi 顺利走过去，你**看到**为什么对（动画演示完整正确过程），不是打个勾。
- 答错：动画演示到一半卡住/JiJi 掉回原点，你**看到**为什么走不通，然后自己重试。

**值得抄的三条**：

1. **反馈要"演出后果"，而不是判分**。海螺喵现在答错只是 AI 换个说法；应改成"海螺真的撞墙/沉底"，让错误**可见**。
2. **极简屏幕**——没有乱跳的怪物、没有吵闹音乐，注意力全在数学上。（与 Prodigy 的教训呼应）
3. **目标恒定**——所有关卡都是"让海螺到达某处"，降低孩子每关重新理解规则的负担。

## 3. 洋葱学园（1.3 亿用户，中国初中数学第一）

**不靠炫技，靠把抽象"演"出来**：负数放进温度计/海拔，函数系数拖动实时看图变化。

**对海螺喵最重要的两条纪律**：

1. **每节 5–8 分钟，只讲一个知识点**——卡死时长，完课率 80%+。厌学孩子绝不能面对一大段文字或一长串追问。
2. **追本溯源**——不直接抛结论，讲清"为什么公式这样变"。但注意：洋葱是**看动画**（被动），海螺喵的优势应是**动手做**（主动），比洋葱更进一步。

---

## 4. Prodigy（Pokémon + 数学：既是范本也是警告）

**核心隐喻**：做题 = 释放技能打 Boss。答对放大招，答错 Fumble 丢回合。能让抗拒的孩子玩一小时。

**必须避开的四个坑（这些是给海螺喵的红线）**：

1. **奖励与答题脱钩** → 孩子学会"秒点最简单的选项刷奖励"，数学占比低到"10 分钟只做 30 秒题"。**海螺喵红线：贝壳必须由真实的数学动作产生，不能变成薅羊毛。**
2. **答错只给答案不讲为什么** → 无教学。海螺喵的 AI 恰好能补这一块。
3. **激进付费/攀比** → 我们无此问题，但提醒奖励系统别制造"有没有"的焦虑。
4. **审美过于低龄** → 初中生会觉得"太幼稚"。海螺喵的美术要偏"清新治愈"而非"儿童卡通"。

## 6. 提炼：海螺喵的设计语言（可直接指导编码）

### 6.1 核心原则：把"潜水/浮出"从背景变成机制

数轴（大海）天生适合内在整合。有理数几乎每个知识点都能变成"海螺的动作"：

| 知识点              | 现状（西兰花）        | 内在整合后（数学=玩法）                                               |
| ------------------- | --------------------- | --------------------------------------------------------------------- |
| K1 正负数 / K3 数轴 | AI 问、孩子打字       | **拖海螺**下潜/上浮，深度实时显示                                     |
| K5 相反数           | 讲定义                | 一键"镜像翻转"，水上水下对称跳                                        |
| K6 绝对值           | 文字解释"到 0 的距离" | **深度计**读数——不看方向只看离海面多远                                |
| K7 比大小           | 打字答                | 两只海螺比谁潜得深，拖到正确位置才过关                                |
| K8/K10 加减法       | AI 出算式             | `+3 加 −5`：海螺先上浮 3 格再下潜 5 格，**亲手走一遍**，落在 −2       |
| K12 乘法 / 负负得正 | 最难讲                | "转向"机制：负号=掉头，两次掉头又朝原方向（焊进移动逻辑，走不通即错） |

### 6.2 四条硬性设计纪律

1. **手指做数学，不是打字做数学**——核心答题动作改为拖拽/点选海螺，而非键盘输入。
2. **错误要"演出后果"**——答错时海螺真的撞墙/沉底/回弹，让错误可见；不要只让 AI 换句话。
3. **文字极少 + 时长卡死**——单个学习单元 5–8 分钟，AI 单次发言压到 1–2 句。
4. **AI 从主讲退为伙伴**——孩子用手做，AI 只在卡住时点一句、突破时夸一句。把现有 system prompt 的"讲题老师"人格改写为"旁边加油的搭档"。

### 6.3 奖励系统红线

贝壳必须由**真实数学动作**产生（如"亲手走对一次加法路径"），不能由点击次数/停留时长产生，否则重蹈 Prodigy"薅羊毛不学习"的覆辙。
