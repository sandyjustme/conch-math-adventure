# 六维评价体系 · 设计与落地

> 日期：2026-07-15
> 目的：给孩子和家长一套看得见的评估——不是分数排名，是多维成长画像。
> 落地优先级：P1（部署前加基础版），P2（部署后持续迭代）

---

## 六个维度（一张雷达图讲完）

```
        兴趣度
          ▲
         / \
   情绪度   掌握度
        |   |
   自主度   坚持度
         \ /
        迁移度
```

| 维度          | 核心理念                                                   | 一句话给孩子             |
| ------------- | ---------------------------------------------------------- | ------------------------ |
| 🧭 **兴趣度** | 他自己想打开吗？主动探索还是被叫来的？                     | 「你是个探险家吗？」     |
| 📐 **掌握度** | 真的学懂了吗？20 个知识点过了几个？                        | 「你点亮了多少岛？」     |
| ⏳ **坚持度** | 能持续回来吗？连续登录天数、总时长。                       | 「你已经坚持了 X 天！」  |
| 🎮 **自主度** | 自己选路还是跟着走？主动点过哪些功能？                     | 「你走的是你自己的路」   |
| 🔄 **迁移度** | 学到的能用到新场景吗？潜水算术正确率 vs 海龟汤正确率对比。 | 「换个地方你还能认出来」 |
| 💚 **情绪度** | 做题时的体验是正面的吗？有没有因为连着答错就不玩了。       | 「今天数学让你开心吗？」 |

## 每维怎么算（全部有数据来源）

### 🧭 兴趣度

- **自动采集**：每周主动打开次数（非间隔偷袭提醒触发）、单次使用时长
- **算法**：兴趣度 = 日均主动打开 × 0.6 + 日均使用分钟 × 0.4，归一化到 0-100 后再加一段曲线
- **加分项**：主动探索了隐藏菜单（海龟汤/规则怪谈/古深海遗迹）
- **说明给孩子看**：「这周你主动来了 5 次，最长一次玩了 25 分钟。你是真正的探险家！」

### 📐 掌握度

- **自动采集**：masteredNodes 数量、answerRecords 正确率曲线
- **算法**：掌握度 = (已掌握节点数/20) × 50 + 最近 20 题正确率 × 50
- **看到**：「你点亮了 12/20 座岛，最近 20 题对了 16 题。船长！」

### ⏳ 坚持度

- **自动采集**：consecutiveDays 连续登录天数、累计使用天数
- **算法**：坚持度 = 连续天数 × 10（cap 100）+ 总天数 × 2（cap 20 bonus）
- **看到**：「你已经连续来了 8 天，总共来了 23 天。老顾客了！」

### 🎮 自主度

- **自动采集**：去过哪些功能模块（探险/潜水/海龟汤/规则怪谈/遗迹/兑换吧台）、是否自己跳过话题或选关
- **算法**：自主度 = 访问过的模块数/9 × 50 + 是否用过语音 × 10 + 是否点过兑换 × 10 + 是否主动打开藏宝图 × 10 + 是否自己选关 × 20
- **看到**：「你去过 7 个不同的地方，还有 2 个没发现。你喜欢用说话，不喜欢打字。」

### 🔄 迁移度

- **自动采集**：同一知识点在"探险"里的诊断正确率 vs "潜水算术"里的操作正确率、海龟汤破案成功率
- **算法**：迁移度 = (潜水平均通关正确率 × 40 + 海龟汤破案率 × 30 + 规则怪谈过关率 × 30)
- **看到**：「在探险里学懂的，在潜水里也走对了——你把知识带到新的地方了。」

### 💚 情绪度

- **自动采集**：每次退出时离"连续答错 3 次"有多远、答错了有没有继续玩（不是直接关掉）、使用时间是否集中在碎片时间还是大段沉浸
- **算法（慎用——部分数据难采集）**：情绪度 = (1 - 挫败退出率) × 50 + 自我报告得分（简单的一题："今天感觉怎么样？😊/😐/😞"，每周弹一次）× 50
- **看到**：「这周你在挫败后继续试了 3 次。还有一次，错了以后反而笑着说'我再试一次'。」

## 怎么展示

### 给孩子：一张雷达图 + 一句本周总结

- 放在贝壳图鉴底部，每周末自动弹一次
- 六个维度画成六边形，孩子看到的是「你在成长」，不是「你考了多少分」
- 底部一句话：「你这周像个真正的海螺探险家——掌握度涨了，坚持度稳了，下周试试去没去过的地方？」

### 给家长：月度报告（一键导出文本）

```
海螺喵数学探险 · 月度报告
——————————————
本月使用 18 天，主动打开 12 次
掌握知识点：正负数、数轴、相反数、绝对值、比大小、加法、减法（7/20）
潜水算术 38 关通过了 22 关
兑换了 2 次（游戏时间 1 次、小零嘴 1 次）
——————————————
亮点：比大小一关只用了 3 个问题就自己悟了
关注：减法还在练，可以多去潜水走几次
```

## 落地分两期

### 一期（部署前，1 小时内完成）——数据已全，只差展示

- 贝壳图鉴底部加雷达图（SVG 六边形）
- 基于已存储的 answerRecords / masteredNodes / consecutiveDays 自动计算前 5 维（情绪度先暂用纯数据推导，不加自我报告）
- 刷新时实时更新

### 二期（部署后，收集真实数据后迭代）

- 情绪度自我报告弹窗（每周一次：「今天数学让你开心吗？」）
- 家长月度报告导出
- 迁移度加海龟汤/规则怪谈数据采集
- 雷达图上加"对比上周"的变化箭头
