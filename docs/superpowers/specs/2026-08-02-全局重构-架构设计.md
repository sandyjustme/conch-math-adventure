## 0. 摘要

三次失败不是三个产品做坏了，是**同一个假设被证伪了三次**：「把数学藏进她喜欢的娱乐里，她就会顺便消化数学」。海龟汤、规则怪谈、短剧是三次伪装质量递增的重复实验，因变量没有动过——她每次都拆穿伪装，或者拆穿经济系统。

v4 不再做第四次伪装。核心倒转是：**不把数学伪装成娱乐，把数学明示为一份有工资的工作**。每天一班、三张工单、十几分钟、看得见打烊；工资（珍珠）是全产品唯一的货币来源，向下接原有的吃饭兑换和一个新的储蓄目标（她自己说想拼的凤冠）。娱乐（短剧/世界观）退到打烊后的休息室，纯玩、零数学、零产出。

这个倒转的底气来自两条**已被她本人行为验证**的事实：她愿意为了点单权在一个枯燥模块里一天点几百次【实证】；她拒绝的从来不是难度和枯燥，是"被考"【实证】。v4 把这两条组合起来：让她愿意刷的那个"农场"，本身就是修分数断点的真练习；同时用"计件完工"的框架替代"答题判分"的框架，让评价从交互里彻底消失。

## 1. 我们到底在哪：三次失败是同一个假设的三次证伪

### 1.1 三次尝试的共同结构

|        | 载体               | 载体来源       | 数学怎么进的             | 死法                                                             |
| ------ | ------------------ | -------------- | ------------------------ | ---------------------------------------------------------------- |
| 第一次 | 海龟汤             | **她自己提议** | 汤底藏数学机制           | 「变成了数学」，从此不碰【实证】                                 |
| 第二次 | 规则怪谈           | **她自己提议** | 极简题目 + 挂珍珠        | 退化成刷分工具，一天 1000+ 珍珠【实证】                          |
| 第三次 | 短剧（地下十三层） | 家长 + AI 写   | 剧情困境即题（mathGate） | 跳着看完，「幼稚、太简单、不够精彩」，只对季末点单权兴奋【实证】 |

三次的公式一致：**找到她喜欢（或可能喜欢）的容器 → 把数学/货币灌进去 → 她要么识破数学（弃容器），要么识破经济（弃数学）**。伪装质量一次比一次高——v3 甚至有五条硬约束、程序化二次校验、禁术语禁裸数字——结果没有变化。当一个假设在伪装质量递增的三次实验里都失败，问题不在执行，在假设本身。

值得记录的是：项目在 7 月 11 日的竞品拆解里就自我诊断过这叫「裹了巧克力的西兰花」，并开出了「内在整合」的药方。但 v3 的 mathGate 依然是外在整合——故事停下来，让她做一个判断，故事再继续。**故事的节奏被题打断的那一秒，就是伪装暴露的那一秒**【判断】。她是重度叙事消费者（听大量小说、《绝世唐门》重看多遍），对"故事节拍"和"伪装成故事节拍的考题"的分辨力，比我们的伪装能力强。

### 1.2 失败定律的机制化

原始归纳：「她喜欢的东西，一旦被明显地数学化或货币化，就会死。」

机制拆开看是两条：

1. **数学化 = 容器污染**。她喜欢的东西是她的领地（海龟汤、规则怪谈是她提议的；小说是她自己写的）。数学进入领地，等于把"她的东西"改造成"大人要她做的事"，领地失守，整个容器被抛弃。死得最快的恰恰是她最喜欢的两个容器【实证】。
2. **货币化 = 优化目标注入**。一旦挂上可兑换货币，她会立刻把该活动重新理解为"赚钱工序"，并找到成本最低的路径。v2 六张卡并联通向同一货币，她精确地找到最便宜那张并且只走那张【实证】。

推论（v4 的两条铁律）：

- **铁律 A：她主动提议、主动创作的任何内容，永远不接数学、永远不接货币。**（她的 AI 小说尤其如此——那是唯一还活着的自发行为，碰了就是第四次谋杀。）
- **铁律 B：货币只能有一个来源。** 不是"堵漏洞"，是结构上不存在第二条路。v3 已验证单路径确实消灭套利（她没在 v3 里刷分）【实证】——v3 死于内容，不是死于经济结构。这条要继承。

### 1.3 两个被反复混淆的变量

**难度 vs 评价。** 运营观察是「简单嫌弃、难了说太难」，曾被读成"难度校准不可能"。但同一个孩子在规则怪谈里把**极简单**的题点了几百遍毫无怨言【实证】。差别不在题的难度，在框架：

- 评价框架里：简单题 = 「你们觉得我只配做这个」，难题 = 「要证明我不行」。两头都是自尊威胁，所以两头都拒绝。
- 计件框架里：简单题 = 工价好，难题 = 工价差。都与"我行不行"无关，所以都能做。

这个区分是全案最重要的设计资源：**它意味着我们可以从 F1「几分之几」这种四年级内容开始补，而不触发羞耻**——只要它是一张工单，不是一道考题。8 分的孩子既不能显性摸底（家长已否决）也不能从高处开始（必然连错崩盘），"从低处开始且有尊严"是唯一的窄门，而计件框架恰好打开它。

**娱乐 vs 报酬。** 她对"用工作换真实报酬"这个交易本身接受度极高：吃饭换珍珠这个强制卡点她天天履约，farming 行为本质上就是自愿加班【实证】。她抵制的是"假装这不是交易"——把工作涂成游戏。所以 v4 的姿态是把交易摆到明面上：这是活儿，干完有钱，钱能换吃的和你想要的东西。**不伪装，就没有可拆穿的东西。**

### 1.4 吞吐量硬账：短剧结构在算术上就补不完分数

即使 v3 的故事好到她天天追：一集只考一题（硬约束第 5 条），一天 2 集 = **一天 2 次练习**；全季规划 40–50 集 = 总共不到 50 次练习。而把 F1–F7 分数阶梯从 8 分修到"能跟上初一课堂"，保守估计需要 300–500 次首试作答（每层 40–70 次形成初步自动化）【判断，依据练习心理学常识】。短剧作为管道，运力差一个数量级——**这与故事写得好不好无关**。故事可以活着，但不能当管道。

### 1.5 已经验证成立的东西（v4 的地基）

1. 点单权是唯一产生过真实动力的奖励【实证】。
2. 「每天打开 app」这个容器成立（哪怕是强制的）【实证，v3 复盘原话"容器是成立的"】。
3. 她能为清晰、确定的报酬承受大量枯燥重复【实证】。
4. 她对"看得见终点、当天能完成"的事有持久力（数小时拼图，无外部奖励；主动想拼下一幅凤冠）【实证】。
5. 「合作」框架下她能坦然说"这块我不会，你来"（拼图电路部分）【实证】。
6. 数轴拖拽这个交互形态没有被抱怨过（潜水算术；抱怨的是题目和奖励）【实证，fractionTasks.ts 注释亦确认】。
7. 单一货币来源结构上消灭套利（v3）【实证】。
8. 工程地基好：engine 纯函数 / data 纯数据 / components 渲染分层干净，133 测试全过，持久化有版本迁移【实证，代码】。
9. 今天刚加的分数模块（F1–F7 阶梯 + 隐形探针 + 奖励不归零 + 数轴拖拽交互）方向与本设计一致，可直接充当 v4 的第一个工件库【实证，代码 `fractionTasks.ts` / `fractionEngine.ts` / `FractionLine.tsx`】。EpisodePlayer 封面页已经埋了「📏 去刻线」入口和"练完才有得看，休息区只消耗主线产出"的注释——作者自己已经在朝这个方向挪了。

## 2. 核心倒转与产品定位

### 2.1 一句话定位（回答问题 1）

> **一间开学前的数学工坊：每天一班、十几分钟、看得见打烊的真练习；工资换今天的饭，储蓄换她想要的凤冠。四周内把分数断层从 F1 修到 F5 以上。**

- **给谁**：这一个孩子。不抽象成"厌学初一学生"——所有设计决策以她的实证画像为准。
- **解决什么**：开学前把小学分数断层和有理数入门修到"9 月能听懂课"的程度。这是家长的真实刚需；「培养兴趣」降级为副产品——三次以兴趣为北极星的设计全部失败，且兴趣如果会来，只会从胜任感来（先能做对，才可能不讨厌）【判断】。
- **成功标准**（可测，不含"自愿打开"——吃饭卡点在，这个指标是脏的）：
  1. 行为：连续 3 周、每周 ≥6 天完成当日班次；
  2. 学习：F 阶梯逐层首试正确率 ≥70% 后推进，9 月 1 日前到 F5（通分），K1/K3/K5/K6/K7 首试 ≥70%；
  3. 卫生：零次「变成了数学」式拆穿（明牌工作无可拆穿），零个新刷分口子；
  4. 干净的兴趣探针（唯一不被卡点污染的信号）：打烊后的自愿行为——加班单使用率、休息室打开率。有则是奖励，无则不影响成败判定。

**为什么这能避开前三次失败**：前三次的成功标准实质是"她爱上它"，于是产品被迫伪装成娱乐、参与娱乐市场竞争（对手是专业网文、短剧和她自己调教的 AI），必输。v4 的成功标准是"活干了、断点修了"，产品只需赢它有垄断权的市场：这个家庭的真实报酬体系。

### 2.2 明确的非目标

- 不追求她"爱上数学"或"自愿打开 app"（观测但不考核）；
- 不做完 20 个有理数知识点（4 周做不完，也不需要——9 月老师会讲，她缺的是听懂课的地基）；
- 不在开学前上第二章"整式的加减"；
- 不做全 app 美术重制（只做四个高价值表面，见 §11）。

### 2.3 对三种失败模式的结构性回答（速查表）

| 失败模式（实证）                | v4 的结构性回答                                                                                   | 残余风险                            |
| ------------------------------- | ------------------------------------------------------------------------------------------------- | ----------------------------------- |
| 「变成了数学」→ 弃容器          | 不伪装：工坊明牌就是练习，没有可拆穿的伪装；她喜欢的内容（休息室/她的创作）零数学零货币（铁律 A） | 她可能拒绝明牌交易本身 → §14 R1     |
| 多路径通向同一货币 → 走最省力的 | 珍珠只有一个水龙头：完成工件。休息室零产出、拼图不可交易、加班同源且封顶（铁律 B）                | 在工件内部瞎点蒙混 → §6.5           |
| 「被考」→ 两头拒绝              | 完成制不是判分制：无对错界面、重试免费、帮手可叫、换单可用；正确率只进后台路由                    | 计件框架被识破为"变相考试" → §14 R1 |
| 做了很多题不过关没珍珠          | 工资按完成计，保底覆盖当天三餐；卡住自动向下路由（§5），不存在"撞墙无路"                          | 无                                  |
| 没有终点 → 放弃                 | 每天一班三单，打烊即终点；每班掉一块拼图，一幅 8–10 块可数着完成                                  | 无                                  |

## 3. 全局因果结构（回答问题 2）

### 3.1 一条链

```
【课程表 + 路由器】(不可见)
      │  决定今天练什么
      ▼
┌─────────────┐   完成    ┌─────────┐
│  工坊 · 今日一班  │ ───────▶ │  钱包(珍珠) │──┬─▶ 食堂菜单(每日吃饭, 沿用兑换码/家长核销)
│  3 张工单≈12-15件 │          └─────────┘  └─▶ 心愿单(储蓄目标: 凤冠拼图等)
└─────┬───────┘
      │ 完成(与对错无关)
      ├─▶ 拼图墙 +1 块（不可交易、不可购买的完成物）
      │
      └─▶ 打烊 ──▶ 休息室开门（可选：短剧连载等，零数学、零产出）

【作答记录】──(只进后台)──▶ 路由器（决定明天练什么）＋ 家长台
```

**流动的东西只有三种**：珍珠（工坊→钱包→两个出口，单向）、拼图块（工坊→墙，不可逆不可换）、作答数据（工坊→路由器/家长台，她不可见）。模块之间没有别的边。

### 3.2 为什么结构上没有套利

v2 的教训不是"防刷代码写少了"，是**并联结构本身产生套利**。v4 的回答是串联：

- 赚珍珠的路径恰好一条（工坊），无从比价；
- 休息室不产出任何东西，刷它无利可图；
- 拼图块非货币、每天上限 1 块（班次完成掉落），无从积攒变现；
- 加班单从同一个路由器取题（加班 = 多练习）、工价递减、每日封顶 2 单——想多赚只能多学，且有硬顶。

这继承并推广了 v3 已验证的「内容稀缺即防刷」：v4 的稀缺物是"今天的班次"，一天只有一班。

### 3.3 家长要的「学玩交替」的真实版本

家长的原话是"学累了去玩会儿，玩的时候其实也在学，然后再回来"。前半句保留，后半句**必须放弃**——"玩的时候其实也在学"就是被证伪三次的那个假设。v4 的节律是：

> **干完活去玩，玩就纯玩；还想要什么，就再来一单。**

学与玩的交替还在，但边界诚实。玩（休息室、她自己的小说、短剧、躺平）不承担任何教学任务；学（工坊）不伪装成玩。两边都因此变得干净：玩不会再被数学污染而死，学不会再因伪装被拆穿而死。

## 4. 工件契约：让"做题"不触发"被考"

这是 v4 交互层的宪法。"工件"= 一道以操作呈现的练习（拖数轴刻线、把 M 颗珠子放进 N 格、数字键盘输入……）。

### 4.1 完成制，不是判分制

- **工件只有两种状态：进行中 / 完工。** 没有"答错了"这个状态。放错位置＝零件还没装上，可以再装（重试免费、无限、无任何提示音效差异的惩罚色彩）。
- **工资按完工件数结算，与对错、重试次数完全无关。** 首试是否正确、重试几次、耗时多少——全部静默入库，只喂路由器和家长台。她的界面上永远不出现正确率、连对数、掌握度、雷达图。
- **庆祝只庆祝完成**（一单完工、一班打烊、一块拼图落位），永不庆祝"聪明"。成长型思维的正确用法不是夸奖话术，是把评价从场景里拿走。
- 现有 `fractionEngine.computeRoundReward` 的"做了就有、绝不归零"方向正确，但"每答对一题多 1 碎片、对满一半加珍珠"要去掉——**任何与正确率挂钩的可见差额都是变相打分**，她对经济差额的阅读能力已三次实证。工资只随工作量变化。

**为何避开失败模式**：她拒绝的是评价（§1.3）。判分制里错误是"你不行"的证据；完成制里错误只是还没完工的零件。v2 的"做题超过 3 题没奖励就放弃"在结构上不可能重演——完工必有工资。

### 4.2 答案空间铁律（对她的优化能力的敬意）

**计件 + 免费重试**的组合有一个漏洞：二选一的工件可以瞎点蒙混。堵法不是惩罚，是题型准入门槛：

> **付工资的工件，答案空间必须 ≥10。** 数轴刻线（几十个刻度）、数字键盘输入、M 珠入 N 格皆合格；二选一、三选一**禁止进入工单**（二选一只允许存在于不发钱的休息室剧情里）。

这样"瞎点到完工"的期望成本高于"想一下再放"，优化者的理性选择自动变成思考【判断】。配套监控见 §6.5。

### 4.3 帮手与换单：把「我们合作」产品化

拼图卡在电路时她的反应不是放弃，是喊家长"我们合作"【实证】。工件契约里给两个对应权利：

- **叫帮手**：每个工件上有"这个我不想算"按钮 → 帮手（吉祥物）**直接演示一道同模板不同数字的孪生件**（动画走完整个操作，零提问、零"你觉得呢"），然后原件回到队尾。不限次数，每次使用静默记录（对路由器是强信号：这层还没准备好）。关键差异：v1 的 AI 导师是苏格拉底式连环反问——那是审讯框架；帮手是"这块你来"的合作框架，**演示而不追问**【判断，源自合作实证的移植】。
- **换单**：每班 2 次，把当前工件换掉（被换的明天再来）。防止硬卡死引发关 app。使用即记录，路由器降层。

### 4.4 可见反馈白名单

## 5. 诊断与路由：elementaryDeps 真正闭环（回答问题 3）

### 5.1 现状的病根

代码事实【实证】：`knowledgeGraph.ts` 里 14/20 个节点声明了 `elementaryDeps`（几乎全是分数、小数），但全项目对它的唯一消费是 `diagnostic.ts:84` 的一个阈值微调——**声明了依赖，却没有任何内容可路由过去**。她推进到 K8（加法，依赖分数加减）必然撞墙，撞墙之后既无路可退又无工资可拿。这就是"做了很多题却不过关、也没有珍珠"的直接机制。今天新加的 F1–F7 分数题库补上了"有内容可去"，但还没有接上"自动路由过去"。

### 5.2 方案：合并成一张图，让小学内容成为一等公民

不再有"初一图谱 + 字符串形式的小学依赖注记"两张皮。建**统一技能图谱**：

- 节点：`F1–F7`（分数，已有）＋ `D1–D3`（小数：数轴定位/加减/乘除，新增）＋ `K1–K20`（已有）；未来若 F1 仍太难，向下扩 `E` 系（整数运算/口诀）。
- 边：现有 `dependencies`（K 系内部链）＋ **把每条 `elementaryDeps` 字符串编译成指向真实 F/D 节点的边**（如 K8 → F4、F6、D2；K12 → F 乘法节点后补）。`elementaryDeps` 从注释性字段变成图的结构。
- 每个节点挂 2–4 个**参数化工件模板**（§7），而不是固定题目。

这样"补小学"不再是一个特殊流程、一个她会察觉的"降级时刻"——**路由器在同一张图上走到哪，工单就是哪的味道**。她看到的只是今天的工单换了个花样。

### 5.3 「从低起步、快速爬升」= 不摸底的摸底

家长否决显性摸底【实证】。v4 的定位策略：

- 冷启动直接从图的低处开工（F1/D1/K1 混合），**爬升规则激进**：一个节点连续 3 件首试完工即视为"此层无断点"，下一班自动上移。会的层每层只花一两分钟，几天内自然停在真实断点上——定位在她看来只是"这几天的活儿有点太容易了"。
- 现有 `PROBE_SET`（10 题横跨各层、断点从记录里浮现）的思路保留，但**打散进日常工单**（每班混 1–2 件探针），不再作为独立的"第一轮"存在——集中的 10 题异层混测有被识别为测验的风险【判断】。
- `fractionEngine.findBreakpoint / statsFromRecords` 直接升格为路由器的核心，从 F 系推广到全图。

### 5.4 班次编排器（shiftPlanner）

每天一班 = 3 张工单 ≈ 12–15 件，配比：

- **~70% 前沿**：当前断点层的变式（同模板换参数、换皮）；
- **~20% 复习**：`spacedRepetition` 的到期节点（间隔梯度沿用 10min/1d/3d/7d/15d/30d，但**不再做"偷袭弹窗"**——SneakAttackBanner 那种打断式复习退役，复习就是明天工单里的两件活，无仪式感、无标记）；
- **~10% 探针**：1 件断点上方（试探是否可推进）＋偶尔 1 件更低层（保持性抽查）。

**数据面修补**：`answerRecords` 结构沿用（nodeId/correct/latencyMs/timestamp），但 FractionLine 现在写死 `latencyMs: 0`【实证】——v4 必须记真实时延（防蒙混监控和流畅度判断都靠它），并补记 `retries` 与 `helperUsed`。

**为何避开失败模式**：诊断彻底隐形（家长红线）；撞墙自动向下路由 + 完成制工资，"努力却无产出"的死循环被双保险拆除；集中测验形态从产品里消失。

## 6. 奖励结构（回答问题 4）

### 6.1 单水龙头工资

- **唯一来源**：完工工件。基准 1 珍珠/件（可调），一班 12–15 件 + 班次完成奖 → 日入约 15–18 珍珠。
- 碎片、游戏次数两种辅币**废除**（多币种 = 复杂度 + 套利面；v2 实证）。存量按 10:1 向上取整并入珍珠（一次性、写进 v4 迁移）。
- 加班单：打烊后可选，每日 ≤2 单，工价 ×0.7 / ×0.5 递减，题目仍出自路由器。**加班存在的意义是给储蓄目标留合法的多赚通道，同时它天然就是多练**。

### 6.2 吃饭卡点：原位保留，加一条保底

- 兑换机制原样沿用（5 珍珠/次、兑换码、家长核销页）——它是唯一在产生行为的资产，v4 只改它的上游（珍珠从哪来），不动它本身。
- **保底**：完成第一张工单即足够兑当天第一餐；完成整班必然覆盖三餐。"因为数学不好而吃不上饭"这个场景在结构上不存在——既是人道底线，也保住数据干净（挨饿换来的服从没有任何解读价值）。
- 指标污染的诚实处理：只要卡点在，"她是否被内容吸引"就测不准。所以兴趣信号只从**打烊后的自愿行为**读（加班、休息室），卡点内的行为只用于判断"交易是否成立"。

### 6.3 心愿单：储蓄型长目标

菜单分两层：

- **食堂**（日常）：三餐、零食，价格让"正常一班"刚好富余 1–3 珍珠；
- **心愿单**（储蓄）：**实体凤冠拼图**（她主动说想拼的【实证】）定价约 150–250 珍珠 ≈ 2–3 周富余+轻度加班；后续可上架"整晚短剧时间"、手工材料等，家长管理价目。

取舍理由：日常吃饭给的是底线动力，但没有"攒"的形状；她对"看得见终点的长目标"有实证持久力（拼图数小时）。储蓄进度条是把这份持久力接到经济系统上的唯一通道，而且目标物是她自己点名要的东西——**产品不发明欲望，只给她已有的欲望标价**。风险与回退见 §14 R5。

### 6.4 拼图墙：不可交易的完成物

每完成一班，掉落一块**数字拼图**（国风彩灯/凤冠系画风，对齐她已验证的审美），8–10 块拼成一幅，挂进画廊。不可购买、不可兑换、错过不补。

- 它是"进度可视化"的替身：藏宝图/贝壳图鉴那种"点亮了几个知识点"的展示本质是成绩单，属于评价黑名单；拼图墙展示的是**出勤与完成**，无关对错。
- 它复刻的是拼图实证里的动机形状：朝一幅看得见的完整图前进，本身即奖励（她拼长安十二时辰无任何外部奖励）【实证】。
- 它不可交易，所以与经济系统零耦合，砍掉也不伤链路（廉价可证伪，见 §14 R4）。

### 6.5 防刷分析（对她这个已验证的优化者）

| 攻击                | 结构防御                                          | 监控信号                                                                                  |
| ------------------- | ------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 工件内瞎点到完工    | 答案空间 ≥10（§4.2），蒙混期望成本 > 思考         | 首试正确率≈随机基线 且 中位时延 <3 秒 → 收紧题型（加大答案空间/改键盘输入），**不加惩罚** |

| 重复听剧/重开班次   | 休息室零产出；班次一天一班（沿用 v3"稀缺即防刷"） | 无需监控                                                                                  |

## 7. 内容供给策略（回答问题 5）

### 7.1 练习内容：参数化模板为主，AI 靠边

- 工件由**确定性参数化模板**生成（现有 `expressionGenerator` 扩展 + `fractionTasks` 模板化）：同一模板换数字、换皮肤文案，构建期校验（沿用 `validateGraph`/`validateDiveTasks` 的构建期验证模式）。零运行时 AI 依赖：无延迟、无失败态、无质量方差、零成本。
- 变式训练的理论要求（同核心换表面 4–6 种）恰好就是参数化模板的定义——v1 理论在这里落地，而不是在 AI 对话里。

### 7.2 AI 的位置：全部离线，产物过人审

- **运行时 AI 彻底退出她的路径**。AdventureChat（AI 导师）冻结：它是审讯框架（连环反问），且 8 轮放行机制从未真正跑通她这一关【实证：20 点亮 6 过关 4】。
- DeepSeek 的正确用法是**离线批量生产 + 程序化校验 + 家长终审**：休息室剧集续写（`generateEpisode` 管线现成，校验器现成）、工件皮肤文案批量换装（`reskinSoup` 模式现成）。生成失败回落预写内容的机制保留。
- **为什么不与她的 AI 竞争**：她用 AI 生成完全贴合自己口味的修仙小说【实证】，我们的运行时生成在她的评价体系里没有胜算（第三次失败的特殊原因）。但离线管线 + 人工筛选可以把"她的 AI 给不了的东西"做出来：连贯的长线世界观、和实物奖励打通的仪式感。门槛是"好到她不排斥"，这个门槛离线人审能守住，运行时守不住。

### 7.3 铁律 A 的执行细则

她的小说、她提议的玩法、她带进来的任何东西：不出题、不发钱、不进课程表、不做"顺带教学"。产品可以**给予**她的爱好（心愿单上架"AI 写作时长/新拼图"，家长定夺），但永不**征用**。

## 8. 知识点编排（回答问题 6）

### 8.1 排序原则：已知断点优先于主干预习

原始设计"以初一为主干、卡住顺带补小学"成立的前提是**断点未知**。现在断点已知且灾难性（分数，8 分）【实证】，deadline 4 周。已知断点 + 硬期限 ⇒ 直接强攻断点，优于等待"顺带"触发。另一个决定性理由：9 月开学后**老师会系统讲有理数**，她不缺第二个讲有理数的人，缺的是听懂课的地基（分数/小数运算、符号直觉）。预习是锦上添花，补断是雪中送炭。

| 周             | 前沿目标                                                                                 | 混入                                                    |
| -------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------- |

## 9. 会话结构（回答问题 7）

她的持久力只对"看得见终点、当天能完成"的事生效【实证】。单日会话的形状：

```
打开 app ──▶ 今日工单（3 张卡，各 4–5 件，进度格清晰可数）
   每张工单 3–5 分钟，做完一张翻一张
──▶ 打烊结算（全案情绪最高点，美术重点投放处）：
      工资入袋动画 → 拼图块落位 → 心愿单进度条前进
──▶ 打烊页：今日已完 ✅ / 「加班？」(≤2) / 「休息室」 / 「食堂」
──▶ 关掉 app，明天见（打烊状态一直显示到次日）
```

- 总时长 10–15 分钟。**打烊是硬终点**：做完就是做完了，产品主动说"今天到这"。稀缺感 + 终点感是从拼图实证和 v3"内容稀缺"实证里直接搬来的。
- 每一件工件 20–60 秒，节奏对齐她能接受的点击式劳作【实证】，但认知负荷高一档（数轴拖拽已验证可接受）。
- 语音：工单默认**静音**（她读得快，朗读被嫌"太慢很烦"【实证】）；TTS 只服务休息室剧集，语速沿用已调好的 1.15。

## 10. 末日修仙世界观的位置（回答问题 8）

**结论：世界观承载氛围，不承载数学。**"怎么用世界观装数学而不被识破"是个错误的问题——三次失败证明"装"这个动作本身就是失败源。正确的问题是：世界观放在哪里才既讨喜又不会被数学污染。两个安全挂载点：

1. **工坊的皮肤**：工单、工资、食堂的命名与美术可以整套换成末日避难所物资站 / 宗门杂役堂的语言（工单 =「物资清点」「阵纹校准」，珍珠可改叫灵石，打烊 =「宵禁」）。这是纯粹的标签层：**没有剧情承诺、没有提问、没有"故事停下来考你"**。给劳动一层她喜欢的题材外衣是安全的，因为皮肤之下的交易是明牌的——皮肤不藏任何东西，就无所谓拆穿【判断】。
2. **休息室的连载**：现有《地下十三层》资产（世界观 + 5 集 + 生成管线 + 校验器）迁入休息室，**摘除全部 choice/mathGate 与珍珠**，变成纯听/纯读的连载。打烊后开门（完成门控，不是对错门控——门控的是"今天的活干完没"，与聪明与否无关，和吃饭同构）。更新节奏与她的表现完全解耦。她提过"字数太少"【实证】——休息室不受"一集 300–450 字"的教学约束，可以上长章节。
3. **禁止的挂载点**（三次失败的原址）：把题放进小说里；把剧情推进挂在答对上；把她的修仙小说接进任何系统（铁律 A）。

产量策略：**按需生产**。先只把现有 5 集摘题上架，看休息室打开率；她若问"还有吗"再开生产线（离线 AI + 人审，§7.2）。不问，就让它安静躺着——省下的力气全部投给工坊。

## 11. 精致度与美术（回答问题 9）

先修正一个投资判断：她抱怨"画面不够精致"属实，但**精致度不是工作回路的成立条件**——她在最丑的规则怪谈里点了几百次，因为工价对【实证】。精致度真正致命的位置是"以娱乐身份参赛的内容"（短剧输给专业媒体的原因之一）。所以：

- **不做全 app 重制**。美术预算集中砸四个她每天必经、且承担仪式感的表面：
  1. 打烊结算序列（工资入袋 / 拼图落位 / 进度条推进——全案情绪峰值）；
  2. 拼图墙与拼图块本体（国风彩灯/凤冠画风，必须真的好看——这是她已验证的审美点）；
  3. 食堂菜单与兑换仪式（唯一被她喜爱过的功能，值得最好的皮）；
  4. 工坊主界面（气质校准：她嫌"幼稚"，参考审美是她的书架——修仙/末日/国风的沉静质感；萌系吉祥物保留但升级执行，做点缀不做主调）。
- 架构位置：美术 = 设计代币（色彩/字体/间距）+ 静态资源层，与 engine/data 完全解耦，可以独立迭代不碰逻辑。每处 UI 自解释（图例/文字说明），延续既有原则。
- 世界观皮肤（§10.1）与美术升级同一次做，避免返工。

## 13. 迁移路径（回答问题 11）

每步独立可验证，且**第 0 步就是核心赌注的最小实验**——用现成代码，两天内可上。

| 步                       | 内容                                                                                                   | 工作量                 | 独立验证什么                                                                               |
| ------------------------ | ------------------------------------------------------------------------------------------------------ | ---------------------- | ------------------------------------------------------------------------------------------ |
| **Step 0**（1–2 天）     | 默认视图从短剧换成 FractionLine；珍珠唯一来源改为分数轮次；兑换不动。观察 3 天                         | 极小（改路由与发奖点） | **核心赌注**：为了吃饭，她做不做真分数题？基线首试正确率与时延自然浮现（隐形摸底顺便完成） |
| Step 1（2–3 天）         | 班次结构（3 单/打烊页/保底）、完成制工资（摘正确率挂钩）、帮手/换单、货币合并（v4 迁移）、真实时延记录 | 小                     | 完成率是否上升；"没奖励就放弃"是否绝迹；无新刷分口                                         |
| Step 2（3–4 天）         | 统一 skillGraph + shiftPlanner（前沿/复习/探针）、D 系小数与 K 系符号模板                              | 中                     | 路由是否工作：卡 F4 时工单自动变分数味；爬升曲线合理                                       |
| Step 3（2–3 天）         | 拼图墙 + 心愿单（凤冠上架）+ 家长价目管理                                                              | 小                     | 加班单使用率（第一个干净的自愿信号）；储蓄行为是否出现                                     |
| Step 4（3–5 天，可并行） | 四个表面的美术与世界观皮肤；休息室上架（摘题的 5 集）                                                  | 中                     | 休息室打开率（第二个干净信号）；"幼稚"评价是否消失                                         |
| Step 5（开学第一周）     | 跟课模式：课程表指针 + 复习配比调整                                                                    | 小                     | 家长每周 5 分钟能否维护；课堂反馈（能否听懂）                                              |

Step 0–1 合计不到一周，**即使后面全部停摆，也已交付"每天真实分数练习在发生"这个最低价值**。Step 0 观察表（沿用试播三集的观察表纪律）：

| 看什么             | 通过                      | 失败                                   |
| ------------------ | ------------------------- | -------------------------------------- |
| 3 天内完成轮次换饭 | ≥2 天做了 ≥2 轮           | 宁可僵持不做 → §14 R1 流程             |

| 首试正确率 vs 时延 | 有思考痕迹（时延 >5s）    | ≈随机且 <3s（蒙混，收紧题型）          |

## 14. 风险与证伪条件（回答问题 12）

**R1 · 核心赌注塌方——她连明牌交易都拒绝**：宁愿和家长僵持挨饿也不做工单，持续 >2 天。
→ 先降到 1 张工单/天重试一周；仍拒绝 → **工资框架被证伪**，本设计作废。此时唯一诚实的结论是：问题不在产品形态，在交易本身的家庭合法性，需要家长在产品外重新谈判（纸面练习+同一经济也行——app 从来不是承重墙，交易才是）。这是全案最大风险，Step 0 的意义就是花两天把它测出来。

**R2 · 计件框架被识破为"变相考试"**：出现"这不就是让我做题吗"。
→ 注意：这句话在 v4 里**不是失败**——我们本来就明说是做题换工资，无伪装可拆。真正的失败信号是她把"完成制"读出评价味（如帮手/换单被她理解为"承认我不会"）。对策：措辞全面去评价化（"这单先跳过"而非"不会做"），帮手演示永不复述她的错误。

**R3 · 蒙混劳动**：正确率贴随机、时延极短、完工率却高。
→ 已有结构防御（答案空间铁律）+ 监控（§6.5）。若仍发生：收紧题型（键盘输入占比提高），绝不加惩罚（惩罚 = 重新引入评价）。

**R4 · 拼图墙无感**：两周内从不打开画廊。→ 砍掉，零连带（设计上已解耦）。动机全押食堂+心愿单。

**R5 · 心愿单太远导致弃疗**：储蓄进度停滞且加班为 0。→ 降价/上架更近的小目标（3–5 天可达），阶梯化。

**R6 · 断点比 F1 还深**（乘法口诀/整数运算不稳）：F1–F2 首试 <50%。→ 图向下扩 E 系节点，模板照做——架构不变，内容下探。

**R7 · 劳役怨恨转移到数学本身**：完成率持续下滑 + 情绪恶化。这是"明牌工作"路线的深层代价，无法预先排除【判断】。缓解：保底工资、打烊硬终点（不加量）、换单/帮手的控制感、四个表面的尊严感设计。监控：家长每周记一次主观情绪分（产品外，不给她看）。若两周下行 → 缩班次规模（宁少而稳）。

**R8 · 内在动机排挤（overjustification）**：外部奖励压死潜在兴趣。诚实评估：她对数学的内在动机现值为零【实证：零次自愿使用】，无可排挤；等哪天休息室/加班出现稳定自愿行为，再讨论逐步把奖励往长目标端迁移。这是幸福的烦恼，不是当下的约束。

**整体证伪条件**：若 9 月 1 日 F 阶梯未达 F4 且班次完成率 <50%，v4 判定失败——届时不做 v5 伪装轮回，回到"交易的家庭合法性"这个产品外的根问题。

## 15. 与家长两条既有主张的正面分歧（需家长裁决）

1. **「玩的时候其实也在学」——本设计明确放弃。** 理由：这正是被三次证伪的假设（§1）。保留的是学玩交替的节律，砍掉的是玩里藏学的暗度。若家长坚持在娱乐里埋数学，本设计的因果链会重新被污染——这一条是 v4 的地基，不是装饰。
2. **「初一为主干、小学顺带补」——在开学前窗口临时倒转**（§8.1）：4 周内分数是主干、初一是配菜；开学后自动转回跟课为主干、按需补漏。原逻辑在"断点未知"时是对的，现在断点已知且致命，直攻优于顺带。
3. 另有一处对任务书的偏离需说明：**末日修仙未被采纳为数学载体**，但未被抛弃——它降级为皮肤与休息室（§10），理由在 §1.4（运力）与 §1.2（伪装必被拆穿）。若试运行后她对世界观表现出强于预期的黏性（休息室打开率高、主动追问剧情），可以在**不接题、不接钱**的前提下加大休息室投入——但那是加码娱乐资产，不是恢复"故事载数学"。
