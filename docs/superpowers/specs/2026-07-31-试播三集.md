# 试播三集 · 今晚念的

> 用途：验证「追剧感」假设是否成立，决定要不要动工
> 念之前的开场白：**"我看到个挺邪门的故事，念给你听听"** —— 不要说"学习""游戏""练习"

---

## 第 1 集 · 新来的

转学第一天，她被安排在最后一排。

这所学校有个规矩：月考排名前十的，坐三楼；倒数十名的，往地下走。第一次月考，她倒数第三。

老师递给她一张纸，《地下楼层守则》第一条：

> **在地下，楼层数是负的。你在哪一层，就欠学校多少分。**

她笑了一下，心想不就是吓唬人的。

她走进电梯，按下 −2。门关上。

显示屏上除了 −2，还多出来一个数字：**−7**。

她没按过 −7。

这栋楼也没有 −7 层。

---

## 第 2 集 · 守则第二条

−2 层比她想的干净。桌上压着第二条守则：

> **每答对一题，你上升一层。每答错一题，你下降一层。回到 0 层，你就自由了。**

同桌是个很瘦的男生，一直低着头。

"你在几层？"她问。

"我来的时候，是 −3。"

"那现在呢？"

他抬起头，很平静地说："**−11。**"

她想说不可能。但她看见了他校服上的编号——那不是学号。

那是 **−11**。

广播这时响了，是老师的声音："今天的第一题。"

题念完，整个教室没有一个人动笔。

所有人都转过头，在看她。

---

## 第 3 集 · 第一题

广播里的声音很慢：

> **"这栋楼一共十三层地下。−3 层和 −7 层，哪一层离地面更近？"**

同桌压低声音："别答……答错你就下去了。"

她盯着电梯屏幕上那个多出来的 −7。

然后她想起守则第一条：楼层数是负的，你在哪一层，就欠学校多少分。

欠得越多，数字越小，离地面就越远。

**——念到这里停下，问她：她该选哪个？**

> **她选 −3（对）**
> "叮"的一声，电梯屏幕上的 −2 变成了 **−1**。
> 教室里所有人第一次抬起头看她。同桌愣了很久，说："你是第一个。"
>
> **她选 −7（错）**
> 灯灭了一秒。再亮起来的时候，屏幕是 **−3**。
> 同桌轻声说："没事，我第一次也错了。往下一层而已，你还有机会。"

她刚要松一口气，广播又响了：

"第二题——"

同时她看见同桌校服上的编号，从 −11 变成了 **−12**。

他答错了。

可她根本没看见他答题。

## 观察表

| 时点          | 看什么                       | 含义                                 |
| ------------- | ---------------------------- | ------------------------------------ |
| 第 1 集念完   | 有没有摸手机、走开           | 听完了 = 钩子成立                    |
| 第 2 集停下后 | 问不问"然后呢""−11 什么意思" | **核心指标**，问了这条路成立         |
| 第 3 集出题   | 抗拒还是顺手就答             | 答对答错不重要，**愿不愿意答**才重要 |
| 三集念完      | 问不问"还有吗"               | 问了 = 可以动工                      |

**反向信号**：她说"这不就是让我做题吗" → 数学埋得不够深，题要更贴剧情、更晚出现；但故事本身没问题。

**失败判定**：第 2 集停下毫无反应 → 这条路不成立，今晚就到此为止，不写代码。

## 这三集用到的知识点

| 集  | 知识点                     | 怎么嵌的                                     |
| --- | -------------------------- | -------------------------------------------- |
| 1   | K1 正负数                  | 楼层数为负 = 欠分，负数第一次出现不带术语    |
| 2   | K3 数轴                    | "上升一层 / 下降一层 / 回到 0 层" = 数轴移动 |
| 3   | K7 比大小（K6 绝对值直觉） | −3 和 −7 哪个离地面更近                      |

复用了项目原有的"离海面越近越大"直觉，只是把海面换成了地面。
