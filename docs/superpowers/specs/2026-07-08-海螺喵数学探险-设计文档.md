## 一、产品概述

### 1.1 一句话描述

一个面向初一厌学学生的数学学习产品，以海底探险为主题，通过 AI 对话诊断 + 游戏化闯关 + 语音交互，帮孩子从真正卡住的地方开始逐层打怪升级。

### 1.2 目标用户

- **主用户**：小学升初一、数学基础极弱（成绩个位数）、厌学情绪浓厚的学生
- **次用户**：陪伴孩子使用的家长（提供兑换核销、进度了解）

### 1.3 核心问题

初一学渣的数学问题往往不在初一——是小学某个知识点（如分数的意义、负数概念）没建立起来，传统课堂"赶进度"导致裂缝上的楼越盖越塌。同时，孩子已形成"我不是学数学的料"的固定型思维，挫败感高，注意力维持时间短。

### 1.4 核心解决方案

**诊断定位断点 → CPA 情境重建概念 → 变式练习巩固 → 费曼讲解检验 → 间隔偷袭抗遗忘**

底层是知识图谱驱动的自适应诊断引擎，外层是海底探险主题的游戏化包装，中间是语音交互降低阅读门槛。

## 三、诊断定位层

### 3.1 核心逻辑

**倒着测，找到真正的"地基裂缝"。**

不顺着章节讲，而是从当前知识点出发，一旦出错就顺着知识图谱的依赖链往回追问，像医生问诊一样顺藤摸瓜。

### 3.2 诊断路径

```
入口：章节终极大关（如混合运算 K19）
  ↓ 连续出错（≥2次同类错误）
检测前置：K17 乘方 → K12 乘法 → K8 加法
  ↓ 在某处稳定出错
下沉到小学：分数运算 / 小数运算 / 四则运算顺序
  ↓ 定位到真正断点
在此处开始脚手架教学
```

### 3.3 多源诊断数据

不只靠 AI 对话，前端也收集行为数据：

| 数据来源                 | 诊断什么          |
| ------------------------ | ----------------- |
| AI 对话中的回答正确率    | 概念理解          |
| 回答延迟（前端计时）     | 熟练度 / 是否在猜 |
| 游戏角的表现             | 直觉性理解        |
| 同一知识点换题后的稳定性 | 是蒙对还是真会    |

### 3.4 厌学保护

- 诊断藏在故事里，不说"现在开始测试"
- 初始题故意简单（送分题），先让孩子觉得"我行"
- 一旦连续答错，不追问，海小螺说"这个有点绕，我们换个简单的试试"——悄悄回退
- 连续两次答不上来 → 自动退回到最基础的直觉判断题，先找回信心

## 四、脚手架学习层

### 4.1 CPA 三段路径

**C 阶段：具体情境（Concrete）**

```
不是讲负数，而是讲潜水。
"海小螺潜到水下5米，又往下潜了3米，现在它在哪？"
孩子脑子里有画面、数轴上能看到拖动 → 先建立直觉
```

**P 阶段：图示表征（Pictorial）**

```
从潜水情境过渡到数轴上的点和箭头。
"你看，每次往下潜，就是在数轴上往下跳。
你自己拖一下——往下3米是从哪跳到哪？"
在孩子拖动的瞬间形成视觉记忆
```

**A 阶段：抽象符号（Abstract）**

```
只在 C 和 P 都稳稳通过之后，才出现算式 (-5)+(-3)=?
这时候符号不是凭空出现的怪物——
它有画面（潜水）、有图示（数轴跳跃）做支撑
```

### 4.2 认知负荷控制

| 规则                                 | 原因                           |
| ------------------------------------ | ------------------------------ |
| 每次只引入一个新东西                 | 工作记忆容量有限，一次一个变量 |
| 新术语在情境中先出现 3 次再单独说    | 先有经验再贴标签               |
| 例题和练习题用一模一样结构，只换数字 | 先让步骤自动化，再换题型       |
| 关键步骤用固定颜色/图标提示          | 减少视觉搜索负担               |

### 4.3 脚手架搭拆机制

- **搭：** 海小螺示范一步 → 孩子跟着做一步 → "这次你自己来，我在旁边看着"
- **拆：** 同类型连续答对 2 题 → 自动减少提示 → 连续对 4 题 → 进入变式练习
- **拆太快时：** 下一题就错了 → "哎呀我跳太快了，我们重新来"→ 脚手架立刻搭回，无惩罚

## 五、变式练习层

### 5.1 什么是变式

表面变了但核心结构没变。不是出更难的题，而是出"看起来不一样、想的方法一样"的题。

### 5.2 变式类型（以正负数加法为例）

| 类型     | 题目示例                                      | 变什么         |
| -------- | --------------------------------------------- | -------------- |
| 标准情境 | 潜到水下5米，又下潜3米，现在在哪？            | 锚定情境       |
| 情境变式 | 温度从 -5℃ 又降了 3℃                          | 换故事         |
| 表述变式 | -5 减少 3 是多少？                            | 换措辞         |
| 逆向变式 | 现在在 -8 米，刚才下潜了 3 米，原来在哪？     | 逆运算         |
| 缺项变式 | 从 -5 出发，到 -8，是上浮还是下潜了几米？     | 已知两端求变化 |
| 干扰变式 | 水下一个东西在 -5 米，浮上来 3 米，现在在哪？ | 正负号反转     |

### 5.3 节奏

- 同一概念，同一难度，换 4-6 种变式
- 每种变式只做 1-2 道
- 全部做对 → 进入迁移检验层
- 错超过 1 道 → 自动退回脚手架层重新教

### 5.4 与游戏角的配合

轻量变式（比大小、正负判断）放在游戏角：

- 闪卡对战：限时点击判断大小
- 气泡排序：按数字大小排冒出来的气泡
- 海底跳跃：控制海螺跳到正确的数字位置

## 六、迁移检验层

### 6.1 费曼讲解

海小螺用朋友而非考官的口吻：

> "你现在能不能用自己的话，跟我说说负数比大小是看什么？"

- 讲不清楚 → 换个例子再来，不说"不对"
- 讲得清楚 → 进入应用检验

### 6.2 新情境应用

给孩子一个和教学情境完全不同的新问题，看能否迁移：

- 学过潜水情境的负数加法 → 考登山情境的负数加法
- 学过整式加减的合并同类项 → 考应用题里的合并同类项

### 6.3 通过标准

费曼讲解清晰 + 新情境 90% 正确 → 知识点标记为"已掌握"并解锁下一关

## 七、记忆锚定引擎

### 7.1 策略一：间隔偷袭

让学过的知识点像 NPC 一样主动找上门，孩子感觉不到在"复习"。

```
学完 K8（加法）后的时间线：
  ┌─ 10 分钟后：游戏角泡泡里混了 1 道加法题
  ├─ 第 2 天：进咖啡馆时海小螺"顺口"提一道快问快答
  ├─ 第 4 天：学减法时"不小心"混了一道加法
  ├─ 第 7 天：游戏角新解锁的小游戏恰好用到 K8
  ├─ 第 15 天：时间胶囊漂流到海滩，换登山情境再遇 K8
  └─ 第 30 天：最终偷袭，答对后标记为长期记忆
```

间隔梯度：10min → 1d → 3d → 7d → 15d → 30d，每次出现在完全不同的上下文。

偷袭成功的奖励递增（越远的偷袭奖励越大），偷袭失败不回退——只是换个感官通道再教一次。

### 7.2 策略二：情感钉

每个知识点植入一个意外/好笑/有成就感的小瞬间：

| 知识点     | 情感钉                                                 |
| ---------- | ------------------------------------------------------ |
| 负数比大小 | 海小螺搞乌龙："-5 比 -3 大吧？"让孩子纠正 AI，角色反转 |
| 绝对值     | 海小螺被拉成一条只能往前的射线，配上搞笑动画           |
| 相反数     | 海小螺照镜子，镜子里是倒过来的，孩子拖动帮它翻回来     |

### 7.3 策略三：知识钩子

每个新知识点明确"挂"在孩子已经会的东西上。知识图谱的每条依赖边都预写 AI 可调用的钩子话术。

> "减法这件事，你其实已经有钥匙了——还记得镜子里倒过来的海小螺吗？减去一个数，就是加上它在镜子里的样子。"

### 7.4 策略四：多感官编码

| 感官通道 | 实现方式                                        |
| -------- | ----------------------------------------------- |
| 视觉     | 数轴颜色分区、气泡大小=数字大小、正负数颜色标记 |
| 听觉     | 海小螺语调变化（正数欢快、负数低沉）、节奏口诀  |
| 触觉     | 拖贝壳、点泡泡、游戏角操作                      |
| 故事     | 每个知识点绑一个海底场景小叙事                  |

### 7.5 策略五：遗忘预警

系统追踪每个知识点的"最后成功提取时间"：

- 超过阈值 → 不在 UI 弹警告
- 而是：海小螺闲聊时"顺口"提起、游戏角悄悄调高相关泡泡概率、下次探险的故事设定恰好用到它
- **孩子完全不知道自己在被补课**

## 八、语音层

### 8.1 使用场景

| 场景         | 类型         | 说明                       |
| ------------ | ------------ | -------------------------- |
| 海小螺说话   | TTS 语音合成 | 每条 AI 回复自动朗读       |
| 孩子回答     | STT 语音输入 | 按住说话，松开发送         |
| 海小螺打招呼 | TTS + 个性化 | 进咖啡馆时叫名字           |
| 关键反馈     | 音效         | 答对、收集、升级各有音效   |
| 环境         | 背景音       | 咖啡馆轻音乐、海底气泡水声 |
| 小游戏       | 游戏音效     | 跳跃、碰撞、收集音         |

### 8.2 技术方案

- **TTS：火山引擎（豆包 TTS）** — 中文自然度高、价格低、支持流式合成
- **STT：Web Speech API（浏览器原生）** — 够用、免费、零依赖
- **音效/背景音：** 本地音频文件 + Web Audio API

### 8.3 延迟优化

```
Claude API 返回文字（流式）
  ↓ 收到第一句完整句子
立即调用 TTS 合成 → 流式播放
  ↓ 后续句子排队合成
第一句播完无缝接第二句
```

目标：首句播放延迟 < 1.5 秒，后续句子无缝衔接。

### 8.4 用户控制

- 🔊/🔇 声音总开关
- 🎤 语音输入按钮（按住说话）
- 音量独立调节（TTS、音效、背景音分开）

## 九、游戏角

### 9.1 设计原则

| 原则           | 说明                               |
| -------------- | ---------------------------------- |
| 30 秒一局      | 厌学孩子的黄金注意力时长           |
| 零惩罚         | 输了没有损失，只是少拿贝壳碎片     |
| 数学藏在操作里 | 孩子以为在玩游戏，实际在提取知识点 |
| 音量独立       | 独立于主界面的声音开关             |

### 9.2 游戏列表

**海底跳跃（有理数·比大小）**

```
海底气泡从深处冒上来，每个气泡上一个数字。
海小螺站在平台上，孩子左右移动它跳到正确气泡上。
- 碰到正确 → 贝壳碎片 +1
- 碰到错误 → 气泡破裂，重新来
- 一局 10 个气泡，30 秒结束
```

**沉船密码（整式·合并同类项）** — 整式章节解锁

```
宝箱需要输入密码。算式 = 密码，散落的简化结果 = 候选密码。
孩子拖正确结果到密码槽 → 宝箱打开，获得珍珠。
```

**方程天平（一元一次方程）** — 方程章节解锁

```
天平左边=方程左边，右边=方程右边。
孩子通过拖拽操作（等式性质）保持天平平衡求解。
- 拿掉砝码 = 两边同减
- 拆分砝码 = 系数化 1
```

**几何拼图（几何图形初步）** — 几何章节解锁

```
拖拽三角形、长方形等碎片拼出目标图形。
过程自动计算并显示周长和面积。
```

### 9.3 贝壳经济体系

```
主探险（AI 对话）→ 真正突破 → 💎 珍珠 ×1（5 珍珠 = 1 杯咖啡）
游戏角 → 每局表现 → 🌟 贝壳碎片 ×N（10 碎片 = 1 珍珠）
每日首登 → 签到 → 🌟 碎片 ×1
连续 7 天签到 → 额外 → 💎 珍珠 ×1
间隔偷袭成功 → 奖励递增 → 🌟 碎片 ×（1+偷袭级数）
```

- **海小螺打招呼是动态的**：根据上次学习时间、当天周几、上次进度个性化
- **今日探险按钮视觉权重最大**：但不强制——可以径直去游戏角
- **藏宝图只显示已发现岛屿**：未解锁区是迷雾，不显示还剩多少，避免进度压迫
- **兑换吧台可兑换时**：有微弱呼吸光效，不刺眼但恰好的存在感

### 10.3 收藏系统（贝壳图鉴）

| 收藏类型    | 获取方式            | 展示形式                       |
| ----------- | ------------------- | ------------------------------ |
| 🌟 贝壳碎片 | 游戏角、签到、偷袭  | 散落亮片                       |
| 💎 珍珠     | 真正突破（AI 判定） | 5颗一排，满一排可兑            |
| 🐚 稀有贝壳 | 里程碑成就          | 单独展示，每只有名字和获得日期 |
| 🏆 徽章     | 特殊成就            | 挂在图鉴封面的金属徽章         |

**稀有贝壳的设计意图：** 可收藏不可消费——"这是你第一次讲清楚负数比大小那天得到的"。收集本身创造内在驱动，对冲纯物质兑换的衰减。

### 10.4 兑换机制

- 兑换比例：5 珍珠 = 1 杯海螺咖啡（比例可配置）
- 兑换方式：生成兑换码，孩子出示给海螺咖啡核销
- 后期：可考虑接入真实收银系统或家长端确认

### 12.2 数据存储

| 数据               | 存储位置            | 原因                     |
| ------------------ | ------------------- | ------------------------ |
| 贝壳余额、解锁状态 | IndexedDB（浏览器） | 离线可用、读写快         |
| 知识点掌握度矩阵   | IndexedDB           | 诊断引擎频繁读写         |
| 对话历史           | IndexedDB           | 隐私优先，数据不出浏览器 |
| 海小螺长期记忆     | 后端（后期）        | 换设备时连续性           |
| TTS 语音缓存       | 后端 + CDN          | 同句不重复合成，省钱     |

## 十四、AI System Prompt 核心规则

（基于 v3 已验证的 prompt，MVP 中继续迭代）

1. 海底情境包装所有概念，不直接出符号算式
2. 每次只问一件事，一句话讲完
3. 连续答不上来 → 退回到送分直觉题，不允许连续两次没台阶下
4. 费曼检验："你教教我"口吻，不是考官口吻
5. 只在真正突破时给珍珠奖励（`<!--REWARD:1-->`），不滥发
6. 每次回复末尾标注当前知识点定位（`<!--LEVEL:Kx-->`）
7. 语气温暖、好奇、耐心，句子短，像聊天不像布置作业
8. 知识钩子话术优先使用预埋在知识图谱中的钩子
