# 双层海域 · 古深海遗迹 — 设计纲要

> 日期：2026-07-14
> 定位：把小学核心概念变成"古深海遗迹"里的秘密，让孩子在深渊里发现上古知识，而不是"补小学"。
> 原则：同一个人（海小喵）、同一套机制（潜水/海龟汤/规则怪谈）、同一个咖啡世界——只是多了一片更深的、更酷的海域。

---

## 一、从 17 个小学依赖聚成 3 个遗迹群

知识图谱分析结果：17 个小学依赖 → 自然聚集为 3 大集群 → 浓缩成 **8 个可玩的遗迹概念**。

### 🐙 遗迹一：分数深渊（最重要，6 个依赖 → 3 个遗迹概念）

影响 K2(分类)/K4(数轴定位)/K7(比大小)/K8(加减)/K12(乘)/K15(倒数)

| 遗迹概念                     | 覆盖小学依赖         | 建议玩法                                    |
| ---------------------------- | -------------------- | ------------------------------------------- |
| 分数是什么（一块蛋糕切几份） | 分数的意义与分类     | 潜水算术 · 拖拽分蛋糕（分数可视化）+ 海龟汤 |
| 分数在哪儿（数轴上的分数）   | 分数在数轴上定位     | 潜水算术 · 把分数拖到"海底分数刻度"上       |
| 分数怎么算（加减乘+倒数）    | 分数加减法/乘法/倒数 | 规则怪谈 · "深海厨房配方"按分数比例调配     |

### 🗿 遗迹二：运算律祭坛（3 个依赖 → 2 个遗迹概念）

影响 K9(加法交换结合律)/K13(乘法分配律)/K19(四则运算顺序)

| 遗迹概念               | 覆盖小学依赖                  | 建议玩法                                              |
| ---------------------- | ----------------------------- | ----------------------------------------------------- |
| 加法和乘法可以"换着来" | 加法交换律/结合律、乘法分配律 | 潜水算术 · 把算式里的项拖来拖去，看结果变不变         |
| 先算什么后算什么       | 四则运算顺序                  | 规则怪谈 · "上古符文解读"，不按正确顺序念就会触发诅咒 |

### 🏛️ 遗迹三：数感基石（8 个剩余依赖 → 3 个遗迹概念）

| 遗迹概念                   | 覆盖小学依赖                          | 建议玩法                                    |
| -------------------------- | ------------------------------------- | ------------------------------------------- |
| 数是什么（整数/小数/位值） | 整数的认识、十进制/位值概念、数的意义 | 海龟汤 · "古代航海图上的数字为什么那样写"   |
| 乘法是什么意思             | 乘法的意义                            | 潜水算术 · "同样一组贝壳重复几次"           |
| 四舍五入                   | 四舍五入                              | 规则怪谈 · "遗迹守卫只接受四舍五入后的密码" |

## 二、叙事框架：深渊是怎么被发现的

### 入口：咖啡馆的地板下

海螺咖啡馆的墙面挂着一张泛黄的**古航海图**（其实就是现在的藏宝图）。某一天（某个知识点被诊断出"小学断点"后），地图的一角开始泛出幽蓝的光——一个新区域解锁：「海螺深渊」。

海小喵凑过去看了一眼，说：

> "这是老一辈航海人传下来的老地图…有人说海底下还藏着一片更老的废墟，里面的东西连我都认不全。想下去看看吗？"

### 视觉语言

| 表层海域           | 海螺深渊                               |
| ------------------ | -------------------------------------- |
| 海面蓝白渐变、明亮 | 深蓝近乎黑、发光水母、碎裂石柱         |
| 海螺咖啡馆、沙滩   | 古石碑、珊瑚废墟、沉船残骸             |
| 数轴是"大海"       | 数轴是"古代深度尺"，刻度是石板上的凹槽 |

### 世界结构（两种进入方式）

1. **被动触发**：诊断引擎发现某知识点卡壳、且根因在小字缺口时 → 咖啡馆里自动亮起"深渊入口"（视觉提示）
2. **主动探索**：藏宝图里始终有一个"幽暗区域"入口，随时可进

## 三、复用现有的游戏机制（不造新轮子）

| 表层海域已有             | 深渊里怎么用                                                        |
| ------------------------ | ------------------------------------------------------------------- |
| 潜水算术（拖海螺走数轴） | 拖海螺走**分数刻度**（一半/三分之一）；拖**运算项**看交换律是否成立 |
| 海龟汤（破案推理）       | 分数、位值、数的意义——全是"古代文字/事件"包装的谜题，孩子推出来才懂 |
| 规则怪谈（遵守规则存活） | 分数运算顺序、四舍五入——"上古遗迹的诅咒规则"，走错一步触发陷阱      |
| 贝壳/珍珠奖励            | 深渊有独有的**古遗物**收藏，集齐一个遗迹群可兑换限量咖啡馆装饰/称号 |

## 四、试点建议：先做"分数深渊"里的「分数是什么」

这是整个小学知识体系里最有画面感、对初中影响最大、也最容易用你的潜水隐喻讲清楚的一个。

**玩法草图**：

> 屏幕是一片古代沉船的剖面图。船身被海水腐蚀，分成一格格的隔间（分母），其中几格装了发光的珍珠（分子）。孩子要做的，就是**拖动珍珠到不同隔间**，看"一个整体分成几份、取了几份"——这跟你们潜水算术里"拖海螺上浮下潜"是同一个技术栈。

试点跑通后，分数深渊的另外两个概念（分数在哪儿、分数怎么算）可以跟着铺上；运算律祭坛和数感基石比照推进。

---

## 五、与表层海域的衔接

- **诊断引擎**：如果 AI 溯源到一个断点的根子在小学，就在对话里**自然提一嘴**："这个问题好像跟海洋深处某个古老规则有关…要不要先下去看看？" → 给出深渊入口。
- **进度闭环**：深渊概念被攻克后，表层对应知识点的诊断重新评估——如果过关了，探险进度​​自动更新。
- **不强制**：孩子可以选择不下深渊，只在表层跟 AI 硬聊；但深渊提供了一条更酷、更体面的路。
