# 海龟汤 · 重新设计稿（v2）

> 日期：2026-07-12
> 目的：把"一眼看穿的数学题"改成"真正的谜案"。汤面零数字、零术语，数学藏进世界规则，靠提问才挖得出。
> 用途：你和孩子先过目——够味 / 够藏 / 够难了，我再照此重建游戏。

---

## 一、这次改了什么（对照旧版三宗罪）

| 旧版毛病                                          | v2 的做法                                                      |
| ------------------------------------------------- | -------------------------------------------------------------- |
| 汤面直接写 `−5`、`绝对值`、`0号位` → 一眼是数学题 | **汤面纯故事，绝不出现任何数字和数学词**；数学是暗藏的世界规则 |
| 第一碗太简单，一步就答完                          | 每碗都有**红鲱鱼**（故意误导的疑点），要问十几个问题才通       |
| 主持废话多、"接近了"乱鼓励                        | 主持**只答 4 种词**，惜字如金，仪式感就是乐趣                  |

**核心原则一句话**：孩子在破案的那一刻才发现"原来是这么回事"，而不是一开始就看见公式。全程没人告诉他这是数学。

---

## 二、主持规则（海小喵严格执行）

1. 对孩子的每个问题，**只允许回**这四种之一：
   - **是**
   - **不是**
   - **无关**（这个和答案没关系）
   - **这不是是非题哦**（引导他改成"是不是…？"）
2. **不鼓励、不提示、不评价**。不许说"接近了""好问题""再想想"——一个多余的字都不给。
3. 只有当孩子说出的推理**命中"破案判定"的核心**，才破例：说一句"🎉 你破案了！"，再用两三句把汤底和背后的道理讲清楚，然后奖珍珠。
4. "提示"要孩子**主动点按钮**才给，且每碗只给一条极小的提示；绝不主动塞。

**主持示例（感受那个惜字如金的节奏）：**

```
孩子：牌子上是不是写着数字？        海小喵：是
孩子：她是不是潜到了很深的地方？    海小喵：是
孩子：数字越大是不是代表越深？      海小喵：不是
孩子：那是不是越小反而越深？        海小喵：是
孩子：哦！因为往下是负数，越深数字越小！
海小喵：🎉 你破案了！……（此时才解释 + 奖珍珠）
```

## 三、五碗汤（汤面念给孩子听，汤底只有海小喵知道）

### 🥇 第一碗 · 潜水英雄榜

- **汤面**：深海餐厅墙上挂着一块"潜水英雄榜"，谁潜得最深谁排第一。今天更新后，一个新来的女孩排到了第一——可她挂上去的牌子，是全榜**看起来最小、最不起眼**的一块。老顾客全都服气地点头。为什么最小的牌子，代表她去过最深的地方？
- **🔑 汤底**：深度用"海面以下多少米"记，写成带负号的数。越往下，这个数越小（−80 比 −20 还小）。女孩到了 −80，数字最小，却潜得最深。榜是按"数字从小到大"排的，所以最小的排第一。
- **藏的知识点**：负数比大小——负号后面数字越大，反而越小 / 越深。（K7）
- **红鲱鱼**：让人以为"最小"说的是牌子尺寸、女孩年龄、或名气。
- **破案判定**：孩子领悟到"往下是负数，越深数字越小"。
- **难度**：★★☆

### 🥈 第二碗 · 两个记账员

- **汤面**：咖啡馆雇了两个记账员，一个只负责记"进的钱"，一个只负责记"出的钱"，俩人从不说话。年底老板把两本账叠在一起对着灯一看，笑了：**"你俩加起来，等于谁都没干过。"** 明明各记了一整年，怎么会等于什么都没发生？
- **🔑 汤底**：一个记的全是正数（收入），一个记的全是负数（支出），而且每一天金额一样大、方向正好相反（+50 配 −50）。互为相反数，相加得 0，一整年全部抵消，合起来就是 0——像什么都没发生。
- **藏的知识点**：相反数；正负相加为 0、相互抵消。（K5）
- **红鲱鱼**：让人以为是双胞胎 / 其实是同一个人的身份诡计。
- **破案判定**：孩子领悟到"一进一出、大小一样方向相反，加起来正好抵成 0"。
- **难度**：★★★

### 🥉 第三碗 · 灯塔上下一样近

- **汤面**：海面上立着一座灯塔，管理员就站在灯塔和海面相接的地方。一只海鸟停在灯塔顶，一条鱼躲在灯塔正下方的礁石缝里。管理员抬头看看鸟、低头看看鱼，说：**"你俩离我一样近。"** 一个在天上，一个在海里，明明一上一下，怎么会一样近？
- **🔑 汤底**：管理员站在海面（0）。海鸟在海面上方 7 米，鱼在海面下方 7 米。方向相反，但**离海面的距离都是 7 米**，所以一样近。只看距离、不看上下——这就是绝对值。
- **藏的知识点**：绝对值 = 离 0（海面）的距离，与方向无关。（K6）
- **红鲱鱼**：让人以为是视错觉 / 灯塔在水里有倒影。
- **破案判定**：孩子领悟到"一个在上、一个在下，但离海面的距离一样，所以一样近"。
- **难度**：★★☆

### 🏅 第四碗 · 站在头顶的矮个子

- **汤面**：海边一栋大楼，两个人赛跑，看谁能到"最高的地方"。矮个子按了个**小小的数字**，高个子得意地按了个**大得多的数字**。电梯门一开，矮个子却稳稳站在高个子的**头顶上方**。为什么按了大数字的人，反而在下面？
- **🔑 汤底**：高个子按的是地下楼层（负数，比如地下 8 层 = −8）。"8"看着大，可它是负的，在海平面以下。矮个子按的是 3 楼（+3），在上面。负数不管多大，都在 0 以下。
- **藏的知识点**：负数都在 0 以下；正数在上、负数在下。（K1 / K3）
- **红鲱鱼**：让人以为高个子按错了 / 电梯坏了 / 数字被贴反了。
- **破案判定**：孩子领悟到"那个大数字是地下层，是负的，所以在下面"。
- **难度**：★★☆

### 🎖 第五碗 · 什么都没拿到的冠军

- **汤面**：潜水俱乐部年终发两块金牌——"潜得最深"一块，"飞得最高"一块。有个人**两块都没拿到**，全场却起立为他鼓掌，说他"最难得"。他既不是最深、也不是最高，凭什么最难得？
- **🔑 汤底**：他把自己精准停在了**正好海面**的位置——不深不浅、不上不下。海面是 0，是唯一"既不是正数、也不是负数"的地方。冲到最深最高靠猛劲，稳稳停在 0 上反而最难。
- **藏的知识点**：0 既不正也不负，是正负的分界，很特殊。（K1）
- **红鲱鱼**：让人以为他救了人 / 破了别的纪录 / 是裁判。
- **破案判定**：孩子领悟到"他停在正中间的海面，也就是 0，那个既不正也不负的特殊位置"。
- **难度**：★★★

## 四、难度与"抓住没耐心孩子"的设计

- **钩子是"想不通的结果"**，不是奖励——每碗汤面结尾都甩出一个反直觉的怪事，勾住好奇心。
- 红鲱鱼制造"以为猜到了却被否掉"的小挫折与反转，这正是海龟汤上头的地方。
- 后续可加：**提问计数**（"你用了 8 个问题破案，海小喵纪录是 5 个"）、**线索卡收集**、**咖啡馆案卷本**（破一碗解锁一段咖啡馆的隐藏剧情），给孩子"继续下去"的理由。
